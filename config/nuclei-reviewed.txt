# Plantillas Nuclei revisadas para Soryntel Security.
#
# Pertenecen al paquete fijado en el Containerfile (NUCLEI_TEMPLATES_REF, con
# su SHA-256). La imagen extrae SOLO las rutas de esta lista; ninguna otra
# plantilla de la colección comunitaria se instala ni se ejecuta.
#
# Criterios para entrar en la lista (se revisa el YAML de cada una):
#   1. Solo apretón de manos TLS, o peticiones GET, HEAD u OPTIONS.
#   2. Sin cargas, diccionarios ni fuzzing; como máximo dos rutas fijas.
#   3. Sin intentos de inicio de sesión ni credenciales por defecto.
#   4. No modifica nada en el destino (nada de PUT, POST, DELETE).
#   5. Sus extractores no sacan secretos del cuerpo de la respuesta.
#
# Revisadas y rechazadas, con el motivo:
#   http/misconfiguration/put-method-enabled.yaml   sube un archivo con PUT (4)
#   http/exposures/configs/git-config.yaml          extrae credenciales del cuerpo (5)
#   http/exposures/configs/phpinfo-files.yaml       prueba una lista de nombres (2)
#   http/miscellaneous/http-trace.yaml              usa el método TRACE (1)
